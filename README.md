# wushanchi.github.io

GitHub Pages root site. The root page redirects to [Server Board](https://wushanchi.github.io/server_board/).

The dashboard source, collectors, and tests live in [wushanchi/server_board](https://github.com/wushanchi/server_board). The built site is published from this repository's `server_board/` directory, alongside the existing `karpathy-gpt-roadmap/` directory. Run `npm run build` in the source repository and copy `dist/` into `server_board/` before publishing.
